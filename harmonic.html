SEQUENCE / 03

조화수열.

각 항의 역수가 등차수열을 이루는 특별한 형태의 수열.

aₙ = 1 / (a + (n − 1)d)
01 이론 02 일반항 03 실생활 속 예시 04 나의 탐구 05 문제로 이해하기 06 다른 수열과 비교
01

이론

조화수열은 각 항의 역수를 취했을 때 그 역수들이 등차수열을 이루는 수열이다. 따라서 일반적인 수열의 값만 바라보기보다 각 항을 역수로 변환하여 규칙을 발견할 수 있다.

HARMONIC SEQUENCE
1/aₙ = a + (n − 1)d
02

일반항

조화수열의 각 항을 역수로 바꾸면 등차수열의 일반항 형태가 된다. 이를 다시 역수로 변환하면 조화수열의 일반항을 얻을 수 있다.

GENERAL TERM
aₙ = 1 / {a + (n − 1)d}
1/a
1/(a+d)
1/(a+2d)
1/(a+3d)
03

실생활 속 예시

조화수열은 어떤 양 자체보다 그 양의 역수, 특히 단위당 값이나 비율을 살펴볼 때 자연스럽게 나타날 수 있다.

01
TRANSPORT / SPEED

이동 시간과 속도

같은 거리를 이동할 때 속도와 걸리는 시간은 서로 역수 관계를 가진다. 따라서 속도의 변화에 따른 시간을 분석할 때 조화수열적 관계를 생각할 수 있다.

SPEED → 1 / SPEED → TIME
02
PHYSICS / RESISTANCE

병렬 회로의 저항

병렬 연결된 저항에서는 각 저항의 역수를 더하는 방식으로 전체 저항을 계산한다. 역수 관계를 이용한다는 점에서 조화평균과 연결하여 생각할 수 있다.

RESISTANCE → RECIPROCAL → TOTAL
03
WORK / RATE

작업 속도와 소요 시간

같은 양의 작업을 수행할 때 작업 속도가 달라지면 필요한 시간은 속도의 역수에 비례한다. 여러 작업 속도를 비교할 때 조화평균과 관련된 사고를 적용할 수 있다.

RATE → RECIPROCAL → TIME
04
DATA / ANALYSIS

단위당 값의 변화

일정한 간격으로 변화하는 값의 역수를 관찰하면 원래 데이터에서는 보이지 않던 규칙을 발견할 수 있다. 이러한 방식은 실제 데이터를 분석할 때도 활용할 수 있다.

DATA → RECIPROCAL → PATTERN
VALUE → RECIPROCAL → PATTERN

조화수열은 값 자체의 변화가 아니라 그 역수에 숨어 있는 규칙을 바라보는 것이 핵심이다.

04

나의 탐구

실생활에서 직접 수집한 데이터를 수열로 나타내고, 다양한 수열의 형태와 비교하면서 데이터 속에 어떤 규칙이 나타나는지 분석하였다.

MY SEQUENCE PROJECT

일상의 데이터를 수열로 바라보다.

직접 측정한 데이터를 수열로 표현하고 그 값의 변화 양상을 분석하였다. 특히 단순한 등차·등비수열뿐만 아니라 역수형태와 멱함수 형태까지 비교하며 실제 데이터에 가장 가까운 규칙을 찾아보았다.

05

문제로 이해하기

다음 수열을 생각해 보자.

EXAMPLE / 01

1, 1/2, 1/3, 1/4, 1/5, ···

각 항의 역수를 취하면 1, 2, 3, 4, 5, ···가 되어 공차가 1인 등차수열을 이룬다. 따라서 주어진 수열은 조화수열이다.

06

다른 수열과 비교

조화수열은 항 자체가 일정한 차이나 비율을 가지는 것이 아니라, 각 항의 역수가 등차수열을 이룬다는 점에서 다른 수열과 구별된다.

조화수열

1, 1/2, 1/3, 1/4, ···

역수 → 1, 2, 3, 4, ···

역수가 등차수열

등차수열

2, 4, 6, 8, ···

차이 → 2, 2, 2, ···
