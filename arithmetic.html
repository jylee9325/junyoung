SEQUENCE / 01

등차수열.

일정한 차이를 반복하며 변화하는 수열의 가장 기본적인 형태.

aₙ = a₁ + (n − 1)d

01

이론

등차수열은 연속한 두 항의 차이가 항상 일정한 수열이다. 이 일정한 차이를 공차라고 하며 d로 나타낸다. 한 항에서 다음 항으로 이동할 때마다 같은 값을 더하거나 빼는 것이 핵심적인 특징이다.

COMMON DIFFERENCE
aₙ₊₁ − aₙ = d
02

일반항

첫째항이 a₁이고 공차가 d인 등차수열에서 n번째 항은 첫째항에 공차를 n−1번 더한 형태로 나타낼 수 있다.

GENERAL TERM
aₙ = a₁ + (n − 1)d
a₁
a₁ + d
a₁ + 2d
a₁ + 3d
···
03

실생활 속 예시

수열은 교과서 속 숫자의 나열에만 존재하지 않는다. 일상에서 얻은 데이터를 수열로 표현하면 그 안에 숨어 있는 규칙과 변화를 발견할 수 있다.

01
DATA / BATTERY

스마트폰 배터리 충전

시간에 따른 스마트폰의 배터리 충전량을 기록하고, 각 시점의 값을 하나의 수열로 나타내어 충전 과정에서 나타나는 변화의 규칙을 분석한다.

배터리 충전량 → 데이터화 → 수열 분석
02
DATA / ICE

얼음의 크기와 녹는 시간

크기가 다른 얼음의 녹는 시간을 측정하여 크기와 시간 사이의 관계를 수열로 표현한다. 실제 측정값을 비교하며 일정한 규칙이 나타나는지 확인한다.

얼음의 크기 → 녹는 시간 → 규칙 분석
03
DATA / HEAT

인덕션 출력과 물의 끓는 시간

인덕션의 출력 단계를 변화시키면서 물이 끓기 시작할 때까지의 시간을 측정한다. 얻어진 데이터를 수열로 나타내고 출력과 끓는 시간 사이의 관계를 분석한다.

출력 단계 → 끓는 시간 → 수열 모델
04
DATA / SPACE

주차장 유도등의 간격

주차장에 설치된 유도등이나 안내 표시의 위치를 관찰하고 각 위치 사이의 간격을 데이터로 기록한다. 연속된 값의 차이를 비교하여 공간 속에 나타나는 규칙성을 수열의 관점에서 살펴본다.

위치 관찰 → 간격 측정 → 규칙 발견
OBSERVATION → DATA → SEQUENCE → PATTERN

일상에서 얻은 데이터를 단순히 기록하는 것에서 끝내지 않고, 수열이라는 수학적 언어로 변환하여 그 안의 규칙을 찾아본다.

04

나의 탐구

일상에서 직접 얻은 데이터를 수열의 관점에서 바라보고, 데이터 속에 존재하는 규칙을 찾아보는 것을 목표로 한다. 서로 다른 현상을 수열로 표현하고 비교하면서 수학이 실제 현상을 설명하는 방법을 탐구하였다.

MY SEQUENCE PROJECT

일상을 수열로 바라보다.

직접 측정한 데이터를 수열로 표현하고, 등차·등비·조화·계차수열 등의 특징과 비교하여 데이터에 가장 적합한 규칙을 찾아가는 방식으로 탐구를 확장하였다.

05

문제로 이해하기

등차수열의 핵심은 연속한 항 사이의 차이가 일정하다는 것이다. 이를 이용하면 특정 항을 구하거나 두 항 사이의 관계를 빠르게 파악할 수 있다.

EXAMPLE / 01

3, 7, 11, 15, ···

첫째항이 3이고 공차가 4인 등차수열이다. 따라서 n번째 항은 aₙ = 3 + 4(n−1)로 나타낼 수 있다.

06

다른 수열과 비교

수열의 종류는 항 사이의 관계를 어떻게 정의하느냐에 따라 달라진다. 등차수열은 차이를 기준으로 규칙을 찾는 반면, 등비수열은 비율을 기준으로 규칙을 찾는다.

등차수열

연속한 두 항의 차이가 일정하다.

2 → 5 → 8 → 11 → 14

공차 = 3

등비수열

연속한 두 항의 비가 일정하다.

2 → 6 → 18 → 54 → 162

공비 = 3
