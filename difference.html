01

이론

계차수열은 어떤 수열의 연속한 두 항의 차이를 이용하여 새로운 수열을 만드는 방법이다. 원래 수열만 보았을 때 규칙이 복잡하더라도 항 사이의 차이를 조사하면 숨겨진 규칙을 발견할 수 있다.

DIFFERENCE SEQUENCE
bₙ = aₙ₊₁ − aₙ
02

일반항

계차수열의 규칙을 이용하면 원래 수열의 항을 앞선 항과의 관계로 표현할 수 있다. 특히 계차수열이 등차수열을 이루는 경우에는 원래 수열을 시그마를 이용하여 표현할 수 있다.

03

실생활 속 예시

계차수열은 값 자체보다 '얼마나 변화했는가'에 주목할 때 활용할 수 있다.

01
DATA / MOTION

등가속도 운동

일정한 시간 간격으로 물체의 위치를 측정하면 연속한 위치의 차이가 점점 일정한 규칙으로 변화하는 모습을 관찰할 수 있다.

위치 → 변화량 → 규칙
02
DATA / SPEED

자동차의 이동 거리

일정한 시간 간격으로 자동차의 이동 거리를 기록하고 각 시점 사이의 변화량을 비교하면 속도 변화와 관련된 규칙을 분석할 수 있다.

거리 → 차이 → 변화
03
DATA / GROWTH

누적 데이터의 변화

시간에 따라 누적되는 데이터의 값을 기록한 뒤 연속한 값의 차이를 구하면 데이터가 증가하는 방식 자체를 분석할 수 있다.

누적값 → 차분 → 패턴
04
DATA / PATTERN

복잡한 수열의 규칙 찾기

처음에는 규칙이 보이지 않는 수열도 항 사이의 차이를 반복해서 구하면 숨겨진 규칙이 나타날 수 있다.

DATA → DIFFERENCE → PATTERN
DATA → DIFFERENCE → PATTERN

값 자체가 아니라 값의 변화량을 살펴보면 복잡한 데이터 속에서도 새로운 규칙을 발견할 수 있다.

04

나의 탐구

실생활에서 직접 수집한 데이터를 수열로 나타낸 뒤 연속한 항의 차이를 계산하여 데이터 속에 숨어 있는 규칙을 분석하였다.

MY SEQUENCE PROJECT

변화량에서 규칙을 찾다.

원래 데이터의 규칙이 명확하지 않더라도 계차를 구하여 새로운 수열을 만들고, 그 수열의 규칙을 분석하는 방식으로 탐구를 확장하였다.

05

문제로 이해하기

수열 1, 4, 9, 16, 25, ···을 생각해 보자. 연속한 항의 차이를 구하면 새로운 규칙을 발견할 수 있다.

EXAMPLE / 01

1, 4, 9, 16, 25, ···

계차수열은 3, 5, 7, 9, ···가 되며 공차가 2인 등차수열을 이룬다.

06

다른 수열과 비교

등차수열은 처음부터 항 사이의 차이가 일정하지만, 계차수열에서는 원래 수열의 차이를 다시 살펴보면서 새로운 규칙을 찾아낸다는 차이가 있다.

계차수열

연속한 항의 차이로 새로운 수열을 만든다.

1 → 4 → 9 → 16

차이 → 3 → 5 → 7

등차수열

연속한 항의 차이가 일정하다.

2 → 5 → 8 → 11

공차 = 3
